# Vehicle Builder

![ISC License (ISC)](https://img.shields.io/badge/License-ISC-blue.svg)

## Description

This project creates a vehicle builder simulator.  It has the ability of creating 3 types of vehicles (Trucks, Cars, and Motorbikes).  The project was created to apply typescript and object oriented programming.  Key take aways were applying the concepts of object oriented programming.

## Installation

1.  Clone the repository:   git@github.com:JeffC87/VehicleBulder.git
2.  Install inquirer: npm i
3.  Start the application: npm run start.

## Usage

This is a command line application.  The first choices given are to create a new vehicle or select from a pre-built vehicle.  Then there is a variety of options that can be done for the selected vehicle.  Trucks and Motorbikes have some special things that they can do that a car cannot.  Trucks can tow up to the weight that they are permited to tow. And motorbikes can do wheelies.
